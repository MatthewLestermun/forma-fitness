# FORMA — сайт фитнес-студии

Концепт лендинга фитнес-студии в минималистичном тёмном стиле.

## Что есть на сайте

- Первый экран с фото и анимированными счётчиками
- Программы тренировок — клик по карточке открывает запись с выбранной программой
- Расписание по дням недели с записью на конкретное занятие
- Тренеры, отзывы, вопросы-ответы (раскрываются по клику)
- Цены с переключателем «месяц / год»
- Окно записи, мобильное меню, плавное появление блоков при прокрутке
- Адаптив под телефон

## Технологии

Чистые HTML, CSS и JavaScript — без фреймворков. Шрифты Geist / Geist Mono, фото — Unsplash.
